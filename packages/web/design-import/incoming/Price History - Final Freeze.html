0 · Зміни у версії v1.2.1 (W5 · API Integration)

Амендмент до v1.2 FINAL FREEZE. Змінює лише перелічене нижче (затверджено для W5); решта foundations лишаються замороженими.

  • Термін «типова ціна» замість «звичайна ціна» — скрізь (підпис смуги, стат-лейбл, advisory).
  • Стат-лейбли: Зараз · Найнижча · Типова ціна · Зміна.
  • Графік не показує «найвищу» — анотацію піка прибрано (highest лишається внутрішнім полем API).
  • Синій для високої ціни / зростання скасовано → нейтральний/muted. Зелений — лише позитивна вигода.
  • Скорочена копія Empty · мобільна висота графіку ~168px · чипи 44px.
  • Дані: GET /api/books/:id/price-history?period=30d|90d|1y|all (default 90d). Суми у відповіді — копійки, UI форматує у ₴.
  • Нові файли: ph-section.jsx · ph-api.jsx · ph-format.jsx + сторінка Book Details — Price History (W5 API).html.

Контракт API (W5)

GET /api/books/:id/price-history?period=30d|90d|1y|all   // default 90d
response: { bookId, period, currency:"UAH", current, lowest, highest,
            typicalRange:{min,max}, change:{amount,percent},
            points:[ { amount, currency, availability, recordedAt } ] }
// amount — integer копійки; recordedAt — ISO; availability ∈ in-stock|out-of-stock|unknown
// UI: копійки→₴ · «найвища» не показується · out-of-stock зберігає ціну (ніколи 0)

1 · Призначення та принцип

Блок «Динаміка ціни» відповідає на одне читацьке питання: «Зараз вдалий час купувати цю книгу, чи варто зачекати?» Він показує, як рухалася ціна, та де вона стоїть відносно звичайного діапазону цієї книги.

  • Спокій, не біржа. Calm, advisory, readable. Жодної трейдерської естетики: без червоного, без тіків, без миготіння, без нескінченних анімацій.
  • Історія викладає факти; вона не виносить вердикт. Пояснювальний рядок описує об'єктивні спостереження («нижче за типовий діапазон», «−25%»). Жодного «Книговик радить / вважає» — судження залишається за майбутніми AI-функціями Книговика.
  • Зелена ієрархія. Найсильніший зелений — лише «вдалий момент» (ціна нижча за звичайну). Висока ціна — інформативний синій (--brand-blue), ніколи червоний, без тривоги.
  • Backend готовий: append-only снапшоти, наявність зберігається в історії, снапшот створюється при зміні ціни або наявності, підтримуються запити мінімальної ціни. UI лише відображає ці дані.

Блок «Динаміка ціни» розміщується безпосередньо під OffersPanel — і на десктопі, і на мобільному. Порядок заморожений:

11 · Стан помилки новий · заморожено тут

Запит історії може впасти, тоді як решта сторінки (пропозиції, опис) завантажилась успішно. Стан помилки локальний для блоку — він не блокує сторінку і не показує модалку.

  • Перевикористовує каркас .ph-empty — жодної нової візуальної мови. Іконка info (--icon-muted), заголовок «Не вдалося завантажити динаміку», нейтральний бейдж «Тимчасова помилка».
  • Спокій, не тривога: нейтральні/приглушені токени, без червоного, без знаків оклику. Помилка історії — не критична: ціни й кнопка купівлі вже доступні вище.
  • Дія повтору: <Button variant="secondary" size="sm">Спробувати ще раз</Button> під текстом. Повтор перезапитує лише історію цього блоку.
  • Заголовок «Динаміка ціни» і футер присутні. role="alert" на тілі повідомлення для асистивних технологій.

12 · Поведінка історії при out-of-stock

Backend зберігає наявність у кожному снапшоті й створює снапшот при зміні наявності. Тому історія знає періоди, коли книги не було. Заморожені правила відображення:

  • Розрив, а не нуль. Лінія з'єднує лише снапшоти «в наявності». Інтервал відсутності — розрив лінії над приглушеною заштрихованою зоною з підписом «не було в наявності». Ніколи не малювати 0 ₴ — відсутність ≠ ціна нуль.
  • Якщо книги немає зараз: лінія завершується на останній відомій ціні; поточна точка приглушена (--text-faint), без зеленого/акценту. Advisory переходить на факт: «Зараз книги немає в наявності. Остання відома ціна — {N} ₴ ({store}, {дата}).»
  • Статистика в режимі oos: «Зараз» = «—» (або «Немає в наявності»); «Найнижча» і «Типова ціна» рахуються лише з in-stock-снапшотів і показуються як завжди; «Зміна за період» — від останньої відомої ціни (приглушено).
  • Узгоджено із замороженим unavailable-станом Book Details v1.1: мітка наявності в пропозиціях лишається --text-faint, ряди-пропозиції видимі як доказ перевірки.
Схема: розрив «не було в наявності» + приглушена поточна точка

13 · Поведінка перемикача періоду

  • Порядок (заморожено): ['30','90','365','all'] → «30 днів» · «90 днів» · «Рік» · «Весь час». За замовчуванням «90 днів».
  • Це не DS-Chip, а власний контрол .ph-period, стилізований під чипи DS через токени (pill, --surface, --border). role="tablist" / role="tab", aria-selected.
  • Стани чипа: idle — --surface + --border; hover — межа й текст --accent; active (data-on="true") — заливка --accent + текст --text-on-accent.
  • Перемикання — миттєве (calm, без переходів графіку). Змінюються: лінія, смуга, advisory, всі 4 стат, aria-label графіку. Стан локальний (React.useState); інший контент сторінки не зачіпається.
  • Якщо для періоду замало даних — показати ту ж копію, що й Empty, у межах картки (не ламати макет).

17 · Правила взаємодії

  • Перемикач періоду — єдиний інтерактив. Клік → миттєва зміна серії; aria-selected оновлюється; hover → акцент. Без анімації переходу графіку.
  • Графік — display-only. role="img" з повним aria-label (період, зараз, мінімум, типовий діапазон). У v1.2.1 немає tooltip/crosshair/scrub — це навмисно (спокій, не біржа). Майбутній hover-read — окреме розширення, не цей реліз.
  • Анімація: лише calm — поява/скелет-пульс 1.4s. Жодних bounce та нескінченних декоративних циклів на контенті. prefers-reduced-motion: reduce → статика.
  • Дотик: кнопки сторінки (kn-btn) — 44px; чипи періоду — 44px заввишки (заморожене мобільне правило дотику).
  • Фокус: 3px м'яке акцентне кільце (--focus-ring) на чипах і кнопці повтору; навігація з клавіатури по табах періоду.
  • Error retry перезапитує лише історію блоку, не перезавантажує сторінку.

18 · Нотатки імплементації

  • Композиція: рендерити з window.PHChart (PriceHistory / PriceHistoryMobile / ...Empty / ...Loading) + новий ...Error. Дані/копія — з window.PHData. DS-примітиви (Badge · Button · SearchBar · ThemeToggle) — з window.KnyhovoDesignSystem_9fa616.
  • Без Tailwind. Тільки ph-chart.css + токени DS. Жодних нових кольорів, типу, радіусів, тіней — усе через var(--*).
  • Прив'язка до backend: серія = впорядковані снапшоти {date, price, inStock, store}. low = min(price) серед in-stock; usualLow/usualHigh = типовий діапазон (напр. 25–75 перцентиль); change = % від першого до останнього in-stock снапшоту. Мок-серії в ph-data.jsx демонструють формат.
  • curColor-розгалуження (current ≤ usualLow) — єдине джерело «вдалого моменту»; не дублювати логіку в кількох місцях.
  • Геометрія графіку — м'який кубічний сплайн через середини точок (органічно, спокійно), headroom = span × 0.12. Не міняти на «трейдерські» гострі піки.
  • SVG-текст бере токени напряму (fill: var(--…)); за межами SVG усе — currentColor/класи.
  • Усі стани зберігають заголовок і футер; блок ніколи не схлопується, лише міняє внутрішній вміст.

19 · Не змінювати

  • Розміщення — завжди безпосередньо під OffersPanel.
  • Порядок і лейбли періодів (30 / 90 / Рік / Весь час), дефолт «90 днів».
  • Набір і порядок 4 статистик; ієрархія кольорів (good=green, high=нейтральний/muted, типова=muted).
  • Концепт смуги «типова ціна» (діапазон, не одна референс-лінія).
  • Принцип «історія = факти», без вердиктів Книговика в advisory.
  • Теплі поверхні скелета; дзеркальна структура завантаження; reduced-motion статика.
  • Чесність Empty; нейтральність Error (без червоного, без модалки); розрив (не нуль) для out-of-stock.
  • Спокійна, display-only природа графіку (без tooltip/scrub у v1.2.1).
  • Токени, типографіка, радіуси, тіні DS v1.0 та всі захищені бренд-активи (лого, маскот).
