Матриця деградації · десктоп

Один селектор керує всім: show (≥2 книги, інакше секції немає), cap (4 десктоп · 8 мобільний) і «усі книги автора →» (коли книг більше за cap). Полиця ніколи не показує плейсхолдери, щоб заповнити сітку. Десктопні приклади — на повну ширину контенту Book Details (саме там живе сітка 4-up).

Багато книг → cap 4 + «усі книги автора (N) →»
3 книги → 3 звичайні картки · без «усі», без добивання
1 книга → секцію омітнуто (нижче поріг)
0 книг → секцію омітнуто

Мобільний рейл · свайп · світла + темна

Горизонтальний рейл (успадковано з мобільних полиць Book Details v1.1): картки 168px, обрізаний край натякає на скрол, scroll-snap для спокійного свайпу, трейлінг-картка «усі книги автора». 44px цілі дотику.
