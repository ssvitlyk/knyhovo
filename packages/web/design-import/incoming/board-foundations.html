01 · Foundations

Токени, типографіка та бренд-активи — джерело істини для всіх екранів. Нічого тут не вигадано: значення читаються напряму з токенів дизайн-системи.

Колір · світла тема

Тепла палітра. Мідний (copper) — акцент світлої теми.

Колір · темна тема

Near-black ink. Світло-помаранчевий (amber) — акцент темної теми.

Типографіка

Lora (serif) — заголовки, дисплей, ціни, акцентний рядок. Inter (sans) — текст, UI, кнопки.
