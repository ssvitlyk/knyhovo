Executive Summary

Цей документ є технічною специфікацією для MVP-реалізації розділу «Добірки» на Knyhovo. Архітектура, IA, UX, SEO та обсяг затверджені в Collections — UX Strategy v1.0 (23.06.2026). PRD не переглядає рішення — він транслює їх у інженерні вимоги.

API Contracts

GET /api/collections/hub

SSR endpoint. Повертає всі дані для хабу в одному запиті. Кешується на сервері (5 хв).

// Request: GET /api/collections/hub // Response 200: { "featured": { "collection": Collection, "previewBooks": BookCardData[3] }, "dynamic": Collection[6], // ordered by display priority "editorial": Collection[2], // knyhovyk-radyt, pryhovani-skarby "genres": Collection[] // only collections where bookCount >= 30 }

GET /api/collections/:slug

Метадані добірки. Для SSR-рендеру hero, breadcrumb, SEO тегів.

// Response 200: { "collection": Collection // includes type-specific config fields } // Response 404: { "error": "not_found" } // Response 301: genres with bookCount < 30 → Location: /dobirky

GET /api/collections/:slug/books

Пагінований список книг з сортуванням та фільтрами. Використовується client-side після SSR initial load.

// Query params: page: number // Default: 1 per_page: number // Default: 24 (4×6). Fixed for MVP. sort: SortOption // Default: per collection type genre: string // genre_code filter (for non-taxonomic collections) price_min: number // Kopecks price_max: number // Kopecks in_stock: 0 | 1 // Default: 0 (all) // Response 200: { "books": BookCardData[], "total": number, "page": number, "per_page": number, "total_pages": number } // Response 200 (no results): { "books": [], "total": 0, ... }

GET /api/collections

// Used for sitemap generation and admin. // Response 200: { "collections": Collection[] // all active, sorted by type then priority }
Кешування /api/collections/hub — server cache 5 хв. /api/collections/:slug/books — server cache 60 хв для taxonomic і editorial; 5 хв для dynamic. Cache invalidation при зміні в CMS або оновленні алгоритму.

Для MVP редакційні добірки керуються через мінімальний адмін-інтерфейс або прямий DB-доступ. Повноцінна CMS — V2.

Featured Collection — логіка вибору

  1. Активна editorial collection з featured_from ≤ TODAY ≤ featured_until — пріоритет 1.
  2. Якщо кілька — з найвищим featured_priority (ціле число, більше = вище).
  3. Якщо жодної — показати /dobirky/knyhovyk-radyt (fallback).
  4. Featured Collection оновлюється без редеплою — зміна в CMS/DB + cache invalidation.

Необхідні CMS-операції (MVP)

  • Створити / редагувати редакційну добірку (поля вище)
  • Додавати / видаляти книги за ISBN або title-пошуком
  • Змінювати порядок книг (drag-to-reorder або sort_order поле)
  • Публікувати / архівувати добірку
  • Встановлювати Featured Collection (дати та пріоритет)
  • Перегляд preview перед публікацією
MVP реалізація без CMS Якщо CMS недоступна до запуску: сeedити editorial_collections та editorial_collection_books через SQL migration + expose простий /admin/collections CRUD endpoint. Мінімальний UI: JSON editor або форма з textarea для book_ids.

Частина дев'ята

SEO Implementation Checklist

Meta Tags

  • <title> pattern: [Назва добірки] · Порівняти ціни · Knyhovo. Hub: «Добірки книг · Порівняти ціни · Knyhovo».
  • <meta name="description"> pattern: «N книг у добірці "[Назва]". Порівняйте ціни у 5 книгарнях та знайдіть найкращу пропозицію.»
  • og:title, og:description, og:url на всіх сторінках.
  • og:image — обкладинка Featured книги або дефолтний Knyhovo OG image.
  • <link rel="canonical"> self-canonical на всіх сторінках.
  • Динамічні добірки (page > 1): canonical → page 1 (?page= відсутній у canonical URL).
  • Archived seasonal collections: <meta name="robots" content="noindex, nofollow"> → потім 301 redirect до /dobirky.
  • hreflang="uk" на всіх сторінках (тільки Ukrainian для MVP).

Schema.org

  • Hub /dobirky: CollectionPage + BreadcrumbList.
  • Кожна сторінка добірки: ItemList (numberOfItems = bookCount) + BreadcrumbList.
  • Кожна ListItem: ListItem → Book (name, author.name, offers.price, offers.priceCurrency: "UAH").
  • ListItem лише для першої сторінки (24 книги). Не генерувати для всіх сторінок пагінації.
  • JSON-LD inline у <script type="application/ld+json"> в <head>. SSR-rendered.

Sitemap & Crawling

  • sitemap.xml: 16 URLs при запуску (хаб + 6 dynamic + 2 editorial + 8 genre). Автоматичне додавання при publish нової добірки.
  • Dynamic collections: changefreq="daily", lastmod = час останнього refresh алгоритму.
  • Editorial collections: changefreq="weekly", lastmod = updated_at.
  • Genre collections: changefreq="daily", lastmod = daily.
  • Archived seasonal: видалити з sitemap + 301 redirect → /dobirky.
  • robots.txt: Allow: /dobirky/. Query params (?sort=, ?page=, фільтри) — Disallow або noindex.
  • Pagination: <link rel="next"> / <link rel="prev"> на сторінках > 1.
  • Internal linking: Genre hub card → /dobirky/[genre]. FeaturedBanner → /dobirky/[slug]. RelatedCollections → /dobirky/[slug].

URL Rules (frozen)

  • Всі slugs — українська транслітерація. Ніяких англійських еквівалентів.
  • Slug незмінний після першої публікації (301 redirect при необхідності зміни).
  • Жанрова сторінка з <30 книг → 301 → /dobirky. Не рендерити порожню сторінку.
  • URL query params не індексуються: noindex на filtered/sorted URLs або canonical до base URL.

Accessibility Checklist

Стандарт: WCAG 2.1 AA. Успадковані заморожені правила від Search Results v1.0 залишаються в силі.

Структура та навігація

  • Skip link: <a href="#main-content" class="skip-link">Перейти до вмісту</a> — перший елемент у DOM, видимий при фокусі.
  • <main id="main-content"> landmark на кожній сторінці.
  • Breadcrumb: <nav aria-label="Хліб крихти"> з <ol>. Frozen pattern.
  • Pagination: <nav aria-label="Пагінація">. Active page: aria-current="page". Frozen rule.
  • Genre grid: <nav aria-label="Жанри"> або role="list" + role="listitem".
  • H1 = назва добірки. Один H1 per page. Hierarchy: H1 → H2 (sections) → H3.

Інтерактивні елементи

  • Filter chips: role="group" aria-label="Фільтри", кожен chip: aria-pressed="true|false".
  • Sort control: <select> з <label> або button group з aria-pressed.
  • BookCard: keyboard focusable. Enter/Space activates. Frozen DS rule.
  • Registration prompt: dismissible via Escape. Focus trap утримувати не потрібно (inline, не modal).
  • Touch targets: мінімум 44×44px на всіх кнопках та посиланнях. Frozen rule (Search Results v1.0).
  • Focus indicator: 3px soft accent ring --focus-ring на всіх focusable elements. Frozen DS rule.

Динамічні оновлення

  • При зміні sort/filter: aria-busy="true" на BookGrid, потім false після update.
  • Кількість результатів після фільтрації: aria-live="polite" region з «Знайдено N книг».
  • Skeleton стани: aria-hidden="true" на skeleton blocks (не читати screen readers).

Контент

  • Book cover images: alt="[Назва] — [Автор]". Не alt="".
  • Decorative icons (Lucide): aria-hidden="true".
  • Collection type badge: aria-label="Тип: Динамічна добірка".
  • Color contrast: всі текстові елементи ≥ 4.5:1 (AAA рекомендований для заголовків). Frozen DS tokens забезпечують це.
  • Інформація не передається тільки через колір (badges мають текст).
