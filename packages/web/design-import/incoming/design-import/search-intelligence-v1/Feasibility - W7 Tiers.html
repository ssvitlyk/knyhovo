Feasibility — W7a / W7b / W7c

Кожна спроможність шару віднесена до тиру за вартістю реалізації. Орієнтир для Claude Code: що можна зібрати на фронтенді вже зараз, що чекає на бекенд, а що — майбутній інтелект.

W7a MVP-безпечно. Фронтенд + наявний пошук. Без нового бекенду.
W7b Потребує бекенду. Нові ендпоінти / дані / індекс.
W7c Майбутнє. NLP / ML / збагачені дані.

W7aMVP-безпечно — фронтенд

Будується поверх наявного пошуку. Не блокується бекендом — можна відвантажувати першим.

W7bПотребує бекенду

Залежить від нових ендпоінтів, нормалізації даних або пошукового індексу. Дизайн готовий — чекає на дані.

W7cМайбутній інтелект

Потребує NLP / ML або збагачених метаданих. Дизайн фіксує намір; реалізація — пізніше.

06Послідовність відвантаження

  • Реліз 1 (W7a). Typeahead, ISBN-детект, переходи на точний збіг, порожній стан зі «стежити», помилки, частковий індекс, словникове авто-виправлення. Нуль нового бекенду, крім per-store-статусу у відповіді.
  • Реліз 2 (W7b). Fuzzy suggest-ендпоінт → did-you-mean; модель work→editions → групування + ISBN-видання; агрегації автора → лендинг; черга «попросити додати».
  • Реліз 3 (W7c). NLP-розбір запиту, метадані серій, кросмовний мапінг, семантика.
