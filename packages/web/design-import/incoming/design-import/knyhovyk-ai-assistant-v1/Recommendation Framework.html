Кожна порада пояснює себе

Дев'ять патернів рекомендацій — від «купувати зараз» до «книги немає». Усі мають одну будову: вердикт, причину й рівень впевненості. Книговик ніколи не дає поради без доказу.

Зелений — лише для позитивної цінності. Падіння ціни, вигідний момент, економія, ціль досягнута. Нейтральні стани лишаються приглушеними; червоного не буває ніколи (зростання ціни — спокійним сірим). Максимум один бейдж на блок. Усе — токени DS v1.0.

Одна коротка фраза серифом. Те, що Книговик радить — спокійно й по суті.

03Колір і тон поради

  • Зелений — лише позитивна цінність. Купувати зараз, ціна впала, краща ціна, ціль досягнута, економія. Зелена рамка + ледь тонований фон + зелений вердикт.
  • Нейтральний — усе інше. Зачекати, ціна висока, нове видання, немає в наявності — звичайна поверхня, приглушений текст.
  • Червоного не буває. Зростання ціни — спокійним сірим, не тривожним червоним. Книговик не лякає.
  • Максимум один бейдж на блок. Не нагромаджуємо «−20%» + «найкраща ціна» + «новинка» разом.
  • Інтенсивність = вигода. Сильніша вигода — більше зеленого (рамка + фон + ціна); слабка — лише зелена дельта.
  • Ціна — 240 ₴, серифом, акцентом; стара ціна — приглушено закреслено; книгарня — завжди приглушено.
